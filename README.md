# 🌌 NOVA — Explore the Universe

> An interactive 3D space exploration website built using Vanilla JavaScript, Three.js, and Vite — bringing the universe to life through immersive 3D visuals and interactive experiences.

🚀 **Live Demo:** https://3dnova-abi.netlify.app/

---

## 🌟 About the Project

**NOVA — Explore the Universe** is a modern and interactive 3D space exploration website designed to provide an immersive journey through the universe.

The website combines **Three.js 3D graphics**, **JavaScript animations**, and a **responsive cosmic UI** to create an engaging experience without using any frontend frameworks.

Users can explore planets, interact with 3D models, discover interesting facts about the universe, and experience a procedurally generated Milky Way galaxy.

---

## ✨ Features

### 🧭 1. Navigation Bar

- Cosmic glowing NOVA brand logo
- Smooth navigation between sections
- Home
- Planets
- About
- Contact
- Glassmorphism navigation effect on scroll
- Fully responsive mobile navigation
- Mobile drawer / hamburger menu

---

### 🌍 2. Hero Section

- Animated 2D starfield background
- Twinkling stars
- Starburst glow effects
- Glowing gradient typography
- Interactive 3D Earth
- Rotating Earth animation
- Custom oceans and continents
- Atmospheric glow
- Wispy cloud effects
- Interactive orbit rings
- Quick action buttons

---

### 🪐 3. Interactive Planets

Explore three interactive 3D planets:

- 🌍 Earth
- 🔴 Mars
- 🪐 Saturn

Each planet includes:

- Interactive 3D model
- 360° rotation
- Zoom interaction
- OrbitControls
- Planetary information
- Distance from the Sun
- Planet diameter
- Number of moons

Users can click and drag the planet to explore it from different angles.

---

### 🌌 4. About the Universe

Learn interesting facts about:

- Observable universe
- Speed of light
- Black holes
- Space and galaxies

The section also includes a procedurally generated **3D Milky Way Spiral Galaxy** created using Three.js particles.

✨ Features:

- 8,000+ glowing particles
- Spiral galaxy structure
- Interactive 3D visualization
- Dynamic particle movement

---

### 📡 5. Contact Section

Includes an interactive communication interface with:

- Message launch form
- Simulated transmission feedback
- Deep-space signal card
- Observatory communication card
- Interactive UI elements
